# 数字证书分析报告

📊 **执行摘要**
本次对未知系统的数字证书分析于2026年4月1日完成，共发现3张证书。总体状况**基本可控**，但存在**显著的安全隐患**。所有证书当前均有效且未过期，但加密强度分布不均，且存在一张高风险的自签名证书。证书颁发机构（CA）来源混杂，包含一个不受信任的私有CA，增加了供应链攻击风险。发现一张证书未配置主题备用名称（SAN），可能导致兼容性问题。

**关键指标：**
*   ✅ 有效证书：3张 (100%)
*   ⚠️ 中等强度加密证书：1张 (33.3%)
*   🔴 自签名/私有CA证书：2张 (66.7%)
*   📈 强加密证书：2张 (66.7%)

🔍 **详细发现**
1.  **加密强度分析**：发现3种密钥类型。
    *   **高强度 (66.7%)**：2张证书使用RSA 2048位密钥，符合当前主流安全标准。
    *   **中强度 (33.3%)**：1张证书仍在使用**RSA 1024位**密钥。该强度已被NIST等标准机构视为不足，易受暴力破解攻击，是明确的安全短板。

2.  **颁发机构信任链分析**：
    *   **公开可信CA (33.3%)**：1张证书由DigiCert颁发，属于全球公认的信任根，信任链完整。
    *   **私有/企业CA (33.3%)**：1张证书由“DFL_PV_NISSAN Sub CA”颁发。其信任依赖于内部CA根证书的部署和管理，若根证书泄露或管理不当，将危及所有由其签发的证书。
    *   **自签名证书 (33.3%)**：1张证书为自签名（`HTTPS-Self-Signed-Certificate-...`）。此类证书**不被任何客户端信任**，通常用于测试或内部服务，若用于生产环境，会引发浏览器警告，并无法验证服务器真实性，存在中间人攻击风险。

3.  **证书扩展属性分析**：
    *   **主题备用名称 (SAN)**：仅1张证书配置了SAN扩展（包含19个域名）。另外2张证书未配置SAN。对于现代TLS连接（尤其是多域名环境），缺少SAN扩展可能导致证书验证失败。
    *   **密钥用途**：所有证书的密钥用途设置基本正确，均包含“数字签名”和“密钥加密”，符合服务器身份验证要求。

🎯 **风险评估**
| 风险项 | 风险等级 | 说明 |
| :--- | :--- | :--- |
| **使用RSA 1024位弱加密证书** | **高危** | 加密强度不足，易被破解，导致通信内容泄露。 |
| **存在自签名生产证书** | **高危** | 无法建立可信身份验证，易遭受中间人攻击，且导致终端用户信任警报。 |
| **依赖私有CA证书** | **中危** | 私有CA的自身安全和管理水平直接影响证书安全性，存在供应链风险。 |
| **证书缺少SAN扩展** | **低危** | 可能导致部分客户端连接失败，影响服务可用性。 |

💡 **紧急程度与建议措施**

**🟥 优先级一（立即处理）**
1.  **替换弱加密证书**：立即将使用**RSA 1024位**的证书更换为至少**RSA 2048位**或更优的**ECC 256位**证书。计划在**1周内**完成。
2.  **淘汰自签名证书**：查明自签名证书的服务用途。若用于生产环境，必须替换为由**公开可信CA**或**受严格管理的私有CA**签发的证书。计划在**2周内**完成。

**🟧 优先级二（短期规划）**
3.  **审计私有CA安全**：对“DFL_PV_NISSAN”私有CA进行安全审计，包括其根证书的存储安全、签发策略、吊销机制等。确保其符合企业安全基线。计划在**1个月内**完成。
4.  **标准化SAN配置**：为所有新申请或续期的服务器证书统一配置SAN扩展，包含所有需要绑定的域名和IP地址。

**🟦 优先级三（持续优化）**
5.  **实施证书集中管理**：部署证书生命周期管理（CLM）平台，实现证书的自动发现、库存、续期和告警，避免证书过期中断服务。
6.  **制定证书策略**：建立并强制执行企业数字证书策略，明确规定允许的CA、最低加密强度、最长有效期（建议不超过13个月）、禁用自签名证书等。

🔧 **最佳实践建议**
*   **加密算法迁移**：规划向**ECC（椭圆曲线密码学）** 证书迁移，其在相同安全强度下比RSA性能更优。
*   **自动化监控**：使用工具对证书有效期、吊销状态、合规性进行持续监控，并设置过期前多级告警（如90天、60天、30天）。
*   **最小化信任域**：严格控制私有CA的签发范围，仅用于无法使用公信证书的内部系统，并定期审查证书清单。
*   **定期分析报告**：每季度执行一次全面的证书资产盘点与安全分析，形成常态化安全运维机制。
