INTRODUCTION

企业证书安全管理
从被动响应到主动感知

在数字化转型加速的今天，企业内网往往部署着数百甚至数千个 HTTPS 服务。自签名证书、过期证书、弱密钥算法、不安全的 TLS 配置——这些隐藏的风险随时可能导致业务中断或安全事件。

证链智审通过被动流量分析与主动域名探测的双轨引擎，配合 AI 智能报告生成，为企业提供全方位的证书安全态势感知能力。

CORE FEATURES

三大核心能力

CERTIFICATE ANALYSIS
证书流量分析

从 PCAP 网络流量中批量提取 TLS 证书，分析算法分布、密钥强度、有效期趋势与签发机构图谱

  • PCAP 批量证书提取
  • RSA / ECDSA 分布统计
  • 密钥长度安全性评估
  • 证书有效期趋势分析
SECURITY SCANNING
域名安全扫描

主动探测域名证书链信任状态，检测自签名、过期、弱密钥及 HTTP 安全响应头合规性

  • 证书信任链验证
  • 自签名证书检测
  • HSTS / CSP 合规检测
  • 多维度安全综合评分
AI REPORTING
